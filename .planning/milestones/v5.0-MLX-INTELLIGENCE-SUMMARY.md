## Lessons Learned

- **Unified Python Path**: Running backend-specific test suites with `PYTHONPATH=backend` ensures all dependencies inside the local virtualenv resolve correctly.
- **Preemptive Cache Tuning**: Adapting MLX unified memory cache limit (80% default) significantly stabilizes local multi-agent reasoning runs.
