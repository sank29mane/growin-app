# Phase 50-02 Plan: Offline GMM Training Engine

**Goal**: Design the background training loop to fit the Gaussian Mixture Model to historical data using DuckDB.

## Requirements
- Ingest historical Volatility and Spread data from DuckDB.
- Fit `sklearn.mixture.GaussianMixture` using `covariance_type='full'`.
- Automatically select optimal components ($K$) using Bayesian Information Criterion (BIC).

## Steps
1. Create `scripts/train_gmm_regime.py`.
2. Connect to DuckDB and execute a bulk extraction query for training data.
3. Fit models for $K \in [2, 3, 4]$ and compute BIC to select the optimal model.
4. Validate that the chosen model avoids degenerate covariance matrices.
5. Save the trained model temporarily for the serialization step.
