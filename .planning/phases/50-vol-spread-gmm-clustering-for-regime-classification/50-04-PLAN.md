# Phase 50-04 Plan: Numba JIT Inference Engine

**Goal**: Implement the Multivariate Normal log-PDF and regime probabilities in strict NumPy/Numba for sub-10-microsecond execution.

## Requirements
- Use `@numba.njit(fastmath=True)`.
- Use the Log-Sum-Exp trick to ensure numerical stability.
- Use Cholesky precisions for rapid Mahalanobis distance calculation.

## Steps
1. Create `backend/coreml/fast_gmm.py`.
2. Implement `fast_gmm_predict_proba(x, weights, means, precisions_chol)`.
3. Validate Numba output against `sklearn`'s native `.predict_proba()` to ensure 100% mathematical parity.
4. Benchmark the Numba function to assert < 10us execution time.
