# Phase 50-01 Plan: Core Feature Engineering (Online Welford & EMA)

**Goal**: Implement $O(1)$ computational modules to track Volatility and Bid-Ask Spread continuously without rolling window overhead.

## Requirements
- Real-time Volatility (EMA of squared returns).
- Real-time Bid-Ask Spread: `(Ask - Bid) / MidPrice`.
- Global Z-score scaling standardizer (Welford's Algorithm).
- Execution time per tick must be < 1 microsecond.

## Steps
1. Create `backend/features/online_vol.py` with an EMA implementation in Numba.
2. Create `backend/features/online_spread.py` to calculate relative spread.
3. Create `backend/features/welford.py` for online Z-score normalization of features.
4. Write unit tests asserting state correctness and micro-benchmarks asserting latency < 1us.
