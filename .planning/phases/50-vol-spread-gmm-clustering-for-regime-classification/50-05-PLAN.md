# Phase 50-05 Plan: MLX QLoRA Adapter Hot-Swap Integration

**Goal**: Seamlessly load the appropriate QLoRA adapter in Apple MLX based on the GMM regime probability, strictly under 2ms.

## Requirements
- MLX memory buffers must be pre-allocated.
- Adapter weights for Regimes 0, 1, and 2 must be kept in CPU/RAM and hot-swapped into Neural Engine/GPU buffers instantly.
- Transition must not cause Python GC spikes.

## Steps
1. Create `backend/mlx/adapter_manager.py`.
2. Pre-load adapter `.safetensors` for all regimes into system memory.
3. Implement `swap_adapter(regime_id)` which overwrites the active MLX weight pointers in-place.
4. Benchmark the swap process to guarantee < 2ms latency, verifying `gc.collect()` is avoided as discovered in Phase 49.
