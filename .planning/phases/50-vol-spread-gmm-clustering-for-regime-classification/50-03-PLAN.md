# Phase 50-03 Plan: Parameter Serialization & State Management

**Goal**: Extract and serialize the GMM parameters (means, weights, precisions_cholesky_) and Z-score factors for the live loop.

## Requirements
- No `scikit-learn` dependencies in the live inference loop.
- JSON or Numpy binary serialization of `weights_`, `means_`, and `precisions_cholesky_`.
- Include the Welford Z-score mean/variance to align online normalization.

## Steps
1. Update `scripts/train_gmm_regime.py` to extract `model.weights_`, `model.means_`, and `model.precisions_cholesky_`.
2. Extract the global mean and variance from the training set.
3. Save all parameters to a compressed `.npz` or `.json` file in the `models/` directory.
4. Create a loader function `backend/coreml/gmm_loader.py` to load these into NumPy arrays.
