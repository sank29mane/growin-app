# Phase 51-04: Evaluation & Testing Strategy

## Goal
Implement the test dataset evaluation suite using pytest and pytest-asyncio to guarantee the <50ms SLA and execution accuracy, alongside dynamic Swarm Gate queries.

## Requirements
- ACC-03

## Must Haves
- [ ] 50 historical sequences of LSE Leveraged ETF market states mapped into tests.
- [ ] End-to-end simulation latency checks ensuring < 50ms total.
- [ ] Assertion that Swarm Gate dynamically queries policies and correctly scales down tail-risk regimes to 0.
- [ ] Assertion that Mean Squared Error (MSE) of simulated vs actual slippage is < 0.05% of trade value across the test dataset.

## Tasks

Create mock historical NumPy array sequences representing 50 LSE Leveraged ETF sequences (e.g., 15 flash crashes, 20 high-spread, 15 regular). Write an async test `test_preflight_latency` using `pytest.mark.asyncio` verifying that a `run_in_executor` simulation call + swarm gate DB query check completes in under 50ms. Write `test_swarm_gate_blocks` verifying `scaled_size == 0.0` when the DB returns a 0.0 multiplier or when `spread > 0.05`.
  </action>
  <read_first>
