# Phase 51-02: Simulation Engine & Telemetry

## Goal
Implement the core in-memory `PreFlightSimulator` and the SQLite monitoring telemetry logic.

## Requirements
- ACC-03

## Must Haves
- [ ] `PreFlightSimulator` is 100% stateless and accepts tick windows (including timestamps, bid, ask, spread, bid_depth, ask_depth as NumPy arrays) and portfolio state explicitly.
- [ ] `PreFlightSimulator.simulate_execution` uses `MarketImpactModel` to simulate trades with zero-copy slicing.
- [ ] Simulation state is thread-safe and stateless.
- [ ] `PreFlightSimulator` computes current simulator drawdown using the explicitly provided portfolio state.
- [ ] `telemetry.py` captures metrics into a local SQLite database on every cycle.

## Tasks

```xml
<task>

It should implement the smart sampling strategy: if `actual_deviation_bps > 5.0` or `size_reduction_pct > 0.5`, it persists the full `tick_window` as BLOB/bytes.
