# Phase 51-03: Trading Loop Integration

## Goal
Integrate the `PreFlightSimulator` and `RiskSwarmGate` into the main async trading loop to intercept order generation and log accurate telemetry post-execution.

## Requirements
- ACC-03

## Must Haves
- [ ] Uses Pydantic `PreFlightDecision` schema for output.
- [ ] Simulator execution is run in a thread pool using `run_in_executor` to avoid GIL blocks on the async loop.
- [ ] Integration triggers re-optimization routines when simulator drawdowns exceed risk limits.
- [ ] Telemetry logging MUST occur after the actual broker fill price is received (to capture true slippage error), not synchronously before order dispatch.

### Task 2: Integrate into Trading Loop (With Post-Fill Telemetry)
