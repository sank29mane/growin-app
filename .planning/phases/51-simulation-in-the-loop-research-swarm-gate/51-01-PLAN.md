# Phase 51-01: Core Models (Market Impact & Risk Swarm Gate)

## Goal
Implement the `MarketImpactModel` for non-linear slippage estimation and `RiskSwarmGate` for capital scaling based on dynamic regime policies.

## Requirements
- ACC-03

## Must Haves
- [ ] `MarketImpactModel` accurately estimates slippage based on L2 depth and trade size using NumPy operations.
- [ ] `RiskSwarmGate` dynamically queries scaling policies from an SQLite/DuckDB source to determine size scaling based on regime.
- [ ] `RiskSwarmGate` blocks execution (size=0.0) if spread > 5.0% of mid-price.
- [ ] No hardcoded scaling multipliers based on regime IDs; all rules must come from the database.
