# PROJECT: Growin

Transform Growin into a self-correcting trading weapon for LSE Leveraged ETFs, optimized for M4 Pro (48GB RAM) and high-fidelity local profit extraction. The platform combines hardware-aware MAS (Multi-Agent System) with a radical Sovereign Ledger UI.

- **Hardware Target**: Apple M4 Pro / Max / Ultra

## Current Milestone: v6.0: Hardened System Exploitation & Alpha Accuracy

**Goal:** Drastically improve overall trading accuracy and maximize system throughput by fully utilizing the M4 Pro (48GB RAM) compute blocks (ANE, GPU, and CPU) and establishing an off-market learning loop.

**Target features:**
- **Tiered Hardware Model Routing**: Run time-series forecasts on the Apple Neural Engine (NPU) via CoreML while running logical swarm agent loops on the GPU via MLX.
- **Vol-Spread GMM Clustering**: Utilize unsupervised clustering in DuckDB to analyze market profile shifts and signal regime changes.
- **2ms Hot-swapping Adapter Router**: Switch local QLoRA adapters on-the-fly dynamically when a regime change is detected.
- **Pre-Flight Simulation Gates**: Research and prototype in-memory backtesting to validate trade proposals before order routing.
- **Adaptive Limit Orders with Dynamic Re-Quoting**: Submit orders with volatility-adjusted price boundaries and actively re-price them to minimize slippage.
- **Autonomic Off-Market QLoRA Learning**: Establish background validation cron jobs that trigger local fine-tuning when model drift is detected.
