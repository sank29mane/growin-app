## 2024-08-26 - Vectorizing MarketImpactModel Order Book Traversal
**Learning:** In performance-critical simulation models (like MarketImpactModel), iterative 'for' loops walking the order book (prices, sizes) can be significantly slower than vectorized NumPy operations. However, when vectorizing, we must use boolean masking to explicitly filter out zero or negative sizes BEFORE applying cumulative sum (`np.cumsum`) and search (`np.searchsorted`) to ensure accurate slippage and execution calculations, correctly mimicking the skip of negative sizes in the iterative loop.
**Action:** Replace iterative order book traversal loops with vectorized NumPy operations (`np.cumsum` and `np.searchsorted`) in simulation engines for significant latency reduction, always including validity checks (boolean masking) for sizes before processing.
